# For Adu — My Pakhi ♡

A mobile-first birthday website for Adu, made by Hossen.

## Put it on GitHub Pages

1. Create a new GitHub repository (for example `adu-birthday`).
2. Upload **everything inside this folder**, keeping the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you a public `github.io` URL. Test it on your phone.
7. Use that final URL to make a QR code. Put the QR code on a card/gift.

## Notes

- The website uses the uploaded photos in `assets/`.
- The background music is generated softly in the browser with Web Audio, so there is no copyrighted music file to upload.
- The first tap starts the audio because mobile browsers normally block autoplay.
- All interactions work without a backend.
